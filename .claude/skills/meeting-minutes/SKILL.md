# 회의록·보고서 자동 정리

## 언제
- 사용자가 클로바 등 음성 변환 텍스트를 붙여 넣거나 첨부하고 회의록/보고서를 요청할 때.

## 결과물 (엑셀 2개, 한 시트·A4 세로 1장)
저장 위치: `클로드 코워크/회의록/YYMMDD_<주제> 회의/` (회의록 폴더는 사용자가 이미 만들어 둠, 앞으로 항상 여기에 저장)
- `YYMMDD_회의록_<주제>.xlsx` : 결론 → 논의 내용 표 → 후속 조치 → 확인 필요
- `YYMMDD_보고서_<주제>.xlsx` : 결재란(담당/팀장/본부장) + 개요 → 주요 내용 → 검토 의견(안) → 향후 계획(안) → 확인 필요
- `클로드 코워크\회의록` 폴더에 접근할 수 있는 세션(Cowork 등)에서만 저장 가능. 접근할 수 없으면 현재 작업 폴더에 만들고 "PC 폴더에는 저장하지 못했다"고 분명히 알린 뒤, 압축(zip)으로 내려받게 한다.

## 순서
1. 텍스트에서 날짜·주제·참석자·장소를 찾는다. 날짜는 없으면 오늘, 주제는 한 줄로 추정(예: `월남관`).
   - 못 찾은 항목은 지어내지 말고 "확인 필요"로 둔다. 질문은 사용자가 정해야 하는 것만 한다.
2. `example_meeting.json` 형식으로 `meeting.json`을 작성한다.
   - 개조식, 결론 먼저, 짧고 쉽게. 전문 용어는 풀어서.
   - 숫자(단가·수량·매출·날짜)는 녹취 그대로 적고, 변환 오류 가능성이 있으면 `unclear`에 넣는다. 계산이 있으면 근거(식)를 함께 적는다.
   - 참석자가 "참석자 1~N"뿐이면 이름을 추측하지 않는다. 역할은 문맥으로 추정했다고 표시한다.
   - 보고서의 "검토 의견"은 제안(안)임을 표시한다. 사용자가 팀장 대신 참석한 경우 개요에 적는다.
3. 실행: `python3 .claude/skills/meeting-minutes/build_minutes.py meeting.json --out-root "<클로드 코워크 경로>/회의록"`
   - 필요하면 `pip install openpyxl`.
4. 검증: LibreOffice가 있으면 PDF로 바꿔 1쪽인지 확인한다. 못 하면 "확인하지 못했다"고 말한다.
5. 답변 형식: 결론 먼저. "확인한 것 / 확인하지 못한 것" 구분, 임의로 정한 것만 알려 준다. 파일 이름이나 기존 파일을 바꾸기 전에는 먼저 묻는다.

## 이름 규칙
- 폴더: `YYMMDD_<주제> 회의` (예: `261022_월남관 회의`)
- 파일: 날짜 6자리 + `_` + 종류 + `_` + 주제
- 같은 이름이 이미 있으면 덮어쓰지 말고 먼저 묻는다.
