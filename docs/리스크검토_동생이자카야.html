"강남 입성" 라이선스 리스크 검토

작성: 이영진 / 2026-10-19 · 동생 이자카야 브랜드 × 논현동 오뎅바 리뉴얼 제안
3줄 요약
  1. 얻는 것은 강남 입성이라는 상징성과 매출 1%(월 수십만 원, 가정치)뿐이고, 잃을 수 있는 것은 브랜드 자체와 오픈 2개월 본점이다.
  2. 이미 망해가는 가게이고 상권 자료도 확인하지 못해, 실패 원인이 상권이어도 책임은 새 간판에 붙는다.
  3. 지금 조건(1%, 노하우 전부 제공)이면 하지 않는 쪽이 안전하고, 한다면 팝업·해지 조항·최소 보장 조건으로만 한다.

1. 기대 효과 대 리스크

구분잘 될 때안 될 때
수익매출 1% (월 3,000만 원이면 30만 원, 5,000만 원이면 50만 원)매출이 낮으면 월 수십만 원도 안 됨
브랜드강남 입성이라는 홍보 문구강남에서 망한 브랜드 이미지, 후기 한 줄이 브랜드 평판이 됨
본점인지도 상승 가능성검증 전(오픈 2개월) 본점까지 동반 하락
통제력-서비스·위생·가격을 남이 운영하는데 책임 이미지는 동생 브랜드

2. 리스크 항목별 점검

리스크내용대응
상권논현동 먹자골목의 유동인구·공실·폐업·매출 통계는 확인하지 못함. 후기 일부는 텅 빈 점포를 언급상권정보시스템 조회, 현장 방문 3회(금요일 밤·평일 저녁·주말 낮)
인수 가게 상태망해가는 원인이 상권인지 가게 문제인지 불명. 채무·임대차 승계 가능성POS 매출 6~12개월 확인, 채무·임대 조건 확인
브랜드·상표상표 등록 여부 불명, 사용 후 소유 분쟁 가능등록 여부 확인, 사용 범위 계약서 명시
레시피 유출계약 종료 후 상호만 바꿔 같은 메뉴 영업 가능비밀유지·종료 후 사용 금지·위약금
법적 성격상표 사용 + 경영 지원 + 대가 수령이면 가맹사업법 대상 가능변호사·공정위 정보시스템 확인
운영 품질위생·서비스 사고가 브랜드로 번짐품질 기준, 시정 요구권, 즉시 해지 조항
정산매출 기준이라 축소 신고 위험POS 조회 권한, 월 정산 자료 제출
중개 이해관계인테리어 업자가 소개 대가·공사비로 이익을 보는 구조인지 불명소개 대가·공사비 부담 주체 확인

3. 그래도 진행한다면 (안전한 구조)

  • 팝업(2~3개월): 성과를 보고 연장 여부 결정. 실패 시 이미지 손상이 작음.
  • 조건부 라이선스: 최소 보장 사용료 + 매출 2~3%, 기준 매출 미달 시 3개월 내 해지·간판 철거.
  • 직영 소규모 시범: 비용이 들더라도 동생 쪽이 직접 운영 통제.
  • 본점 실적 우선: 본점 6개월~1년 매출 실적을 쌓은 뒤 확장 검토.

4. 결정 기준

조건판단
1%, 노하우 전부 제공, 해지 조항 없음하지 않는다
POS 확인 + 상권 확인 + 단기 + 해지 조항 + 최소 보장조건부로 검토 가능
상권·가게 자료를 받지 못함자료 확인 전에는 진행하지 않는다
※ 상권 통계, 법령, 로열티 수치는 이번에 검증하지 못했음. 월 매출·사용료는 가정치. 계약 전 변호사·세무사 확인 필요. 참고: 소상공인 상권정보시스템(sg.sbiz.or.kr), 서울 우리마을가게 상권분석서비스, 공정위 가맹사업정보제공시스템(franchise.ftc.go.kr).
