검토 요청 사항 (변호사님께)
  1. 본 계약이 가맹사업거래의 공정화에 관한 법률상 가맹계약에 해당하는지, 해당한다면 정보공개서 등록 등 의무와 대안 구조(팝업, 단순 상표 사용 허락 등).
  2. 상표 등록 여부 미확인. 미등록 시 출원 시점과 계약상 보호 방안.
  3. 레시피(영업비밀) 보호: 비밀유지, 종료 후 사용 금지, 위약벌 조항의 유효성과 적정 수준.
  4. 매출 연동 사용료와 최소 보장액의 구조, 사업자 간 부가가치세 처리.
  5. 운영 사고(위생·식중독)와 임대차·채무 승계에 대한 책임 분리 방법.
  6. 제3자(인테리어 업자 등) 소개 대가가 있는 경우의 계약상 처리.

※ 제안 조건은 월 정액 + 매출 일정 비율 + 최소 보장, 기간 1년, 위반 시 즉시 해지입니다. 수치는 모두 가정이며 협상 중입니다. 상권·법령 내용은 제가 검증하지 못했습니다.

제1조 (목적)

본 계약은 갑이 보유한 상표(이하 "본건 상표")와 메뉴·레시피(이하 "본건 메뉴")를 을이 아래 매장에서 사용하도록 허락하고, 그에 따른 대가와 권리·의무를 정함을 목적으로 한다.

제2조 (대상)

  1. 본건 상표: [상호/로고], 출원·등록번호 [ ] (미등록 시 "출원 예정" 표기)
  2. 본건 메뉴: 별첨 목록에 기재된 메뉴 및 레시피 [별첨 1]
  3. 사용 매장: 서울 강남구 논현동 [주소 ], 이하 "본 매장". 본 계약은 본 매장에 한하며 다른 장소·온라인·배달·상품 판매에는 허락 없이 사용할 수 없다.

제3조 (허락의 범위)

  1. 갑은 을에게 계약기간 동안 본 매장에서 본건 상표와 본건 메뉴를 사용할 비독점적 권리를 허락한다. [독점 여부·지역 제한: ]
  2. 을은 제3자에게 재허락·양도·담보 제공을 할 수 없다.
  3. 본건 상표와 메뉴에 대한 권리는 갑에게 귀속되며, 본 계약으로 을에게 이전되지 않는다.

제4조 (계약기간)

  1. 계약기간은 [20 년 월 일]부터 1년으로 한다.
  2. 갱신은 만료 [ ]일 전까지 서면 합의로 한다. 자동 갱신하지 않는다.
  3. 개점 후 [3]개월 시점에 제8조의 기준 매출을 점검한다.

  2. 메뉴 전수·세팅 비용: 계약 체결 시 일시금 [ ]원, 선불.
  3. 지급 시기: 매월 [ ]일까지 직전 월분을 갑이 지정한 계좌로 지급한다. 지연 시 연 [ ]% 지연이자.
  4. 세금계산서는 갑이 발행한다.

  1. 매출은 POS 기록 기준 부가가치세 제외 순매출액으로 한다. [ ]
  2. 을은 갑에게 POS 매출 조회 권한 또는 월별 매출 자료를 매월 [ ]일까지 제출한다.
  3. 갑은 사전 통지 후 영업시간 중 장부·POS 자료를 확인할 수 있으며, 매출 누락이 [ ]% 이상이면 확인 비용을 을이 부담하고 추가 사용료와 지연이자를 지급한다.

제7조 (품질·위생·운영)

  1. 을은 본건 메뉴의 레시피, 맛, 가격대, 서비스 기준(별첨 2)을 지키고 관련 법령(식품위생법 등)을 준수한다.
  2. 영업신고, 주류 판매 허가, 직원 고용, 임대차, 세금 등은 모두 을의 명의와 책임으로 하며, 갑은 본 매장의 영업·채무·직원 문제에 대하여 책임을 지지 않는다.
  3. 위생·안전 사고나 고객 민원이 발생하면 을은 즉시 갑에게 알리고 시정한다. 갑은 시정을 요구할 수 있고 [ ]일 내 시정하지 않으면 제11조에 따라 해지할 수 있다.
  4. 갑의 사전 서면 동의 없이 본건 상표의 모양·표기를 바꾸거나 다른 상호와 혼용하지 않는다.

제8조 (최소 성과 기준)

제9조 (비밀유지)

  1. 을은 본건 메뉴의 레시피, 조리법, 배합, 공급처 정보 등 갑이 제공한 자료(이하 "비밀정보")를 계약기간과 종료 후 [ ]년간 비밀로 유지하고, 본 매장 운영 외의 목적으로 사용하거나 제3자에게 공개하지 않는다.
  2. 을은 직원에게 비밀유지 의무를 지우고 위반에 책임을 진다.
  3. 비밀정보를 복제·촬영·반출하지 않으며, 계약 종료 시 모두 반환·폐기한다.

제11조 (해지)

  1. 다음 경우 갑은 서면 통지로 즉시 해지할 수 있다: ① 사용료 [ ]회 이상 연체 ② 비밀유지·품질·상표 사용 범위 위반 ③ 위생·안전 사고로 브랜드에 중대한 손해가 발생 ④ 제6조 자료 제출 거부 또는 매출 은폐 ⑤ 폐업, 파산, 영업 정지 ⑥ 제8조 기준 미달.

제12조 (종료 후 조치)

  1. 계약이 종료되거나 해지되면 을은 즉시 본건 상표와 메뉴 사용을 중단하고 [ ]일 내 간판·메뉴판·표기를 철거하며 SNS·플랫폼 등록 정보를 정정·삭제한다.
  2. 을은 비밀정보를 반환·폐기하고 이를 확인하는 서면을 갑에게 제출한다.
  3. 철거 비용은 을이 부담한다.

제13조 (손해배상·위약벌)

  1. 일방이 본 계약을 위반하여 상대방에게 손해를 입히면 배상한다.
  2. 을이 제9조·제10조·제12조를 위반하면 손해배상과 별도로 위약벌 [ ]원을 지급한다. (적정 금액·유효성 검토 요청)

제14조 (상표 보호)

  1. 을은 본건 상표와 동일·유사한 상표·상호·도메인·SNS 계정을 자기 명의로 등록하지 않는다. 위반 시 즉시 갑에게 이전한다.
  2. 제3자의 침해 사실을 알게 된 때 을은 즉시 갑에게 알린다.

제15조 (관계)

갑과 을은 독립된 사업자이며, 본 계약은 동업·조합·고용·대리 관계를 설정하지 않는다. 갑은 을에 대하여 본 매장의 임대차, 채무, 직원 문제를 연대하거나 보증하지 않는다. (상표권자와 본인이 다른 경우 별도 조항 필요)
